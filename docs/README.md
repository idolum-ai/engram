# Engram Documentation

Start with the root [README](../README.md) to install Engram and create a first
session. Use this index when you need the complete contract for one area.

## Use Engram

- [Telegram commands](telegram-commands.md): generated reference for every
  registered command.
- [Session controls](session-controls.md): replies, saved input, current and

- [Headless operation](headless-operation.md): foreground use, native services,
  local inspection, upgrades, and recovery.
- [GitHub App capabilities](github-app-capabilities.md): enrollment, approval,
  exact commands, renewable grants, revocation, and troubleshooting.
- [Agent compatibility](agent-compatibility.md): supported process, binding,
  screen, and transcript axes.
- [Codex session context](codex-session-context.md) and
  [Claude Code session context](claude-code-session-context.md): opt-in history,
  hooks, disclosure, and failure behavior.
